# Integritetspolicy / Privacy Policy – gta6-clipper

**Svenska:** gta6-clipper är ett privat automationsverktyg som används av repots ägare för att ladda upp
videor till sin egen YouTube-kanal. Verktyget samlar inte in, lagrar eller delar personuppgifter om andra
användare. Åtkomsten till YouTube (scope `youtube.upload` och `youtube.readonly`) används endast för att
ladda upp videor till ägarens kanal och kontrollera ägarens egna uppladdningar. OAuth-token lagras
krypterat som GitHub Secret och delas inte med tredje part. Åtkomsten kan när som helst återkallas via
https://myaccount.google.com/permissions.

**English:** gta6-clipper is a private automation tool used only by the repository owner to upload videos
to their own YouTube channel. It does not collect, store or share personal data of any other users.
YouTube access (`youtube.upload`, `youtube.readonly`) is used solely to upload videos to the owner's
channel and to check the owner's own uploads. OAuth tokens are stored encrypted as GitHub Secrets and are
never shared with third parties. Access can be revoked at any time at
https://myaccount.google.com/permissions. This app uses YouTube API Services; see the YouTube Terms of
Service (https://www.youtube.com/t/terms) and Google Privacy Policy (https://policies.google.com/privacy).
